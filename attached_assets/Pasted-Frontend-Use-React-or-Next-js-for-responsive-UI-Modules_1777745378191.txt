Frontend:
- Use React (or Next.js) for responsive UI.
- Modules: Data Import, Cleaning, Profiling, EDA, Visualization, SQL Editor, AI Assistant, Collaboration.
- Integrate Chart.js/D3.js for interactive charts and dashboards.
- Dashboard builder with drag-and-drop widgets.
- Natural language query box connected to AI backend.
- Role-based navigation (Admin, Analyst, Viewer).

Backend:
- Use Node.js + Express for API routes.
- Database: PostgreSQL with tables:
  - datasets (id, name, source, schema, uploaded_by, created_at)
  - queries (id, dataset_id, sql_text, result, created_at)
  - users (id, name, email, role, password_hash)
  - reports, jobs, audit_logs
- Implement authentication (JWT).
- Endpoints for:
  - Uploading datasets (CSV, Excel, JSON, SQL dumps).
  - Automated data cleaning (missing values, duplicates, normalization, outlier detection).
  - Automated data profiling (summaries, distributions, correlations).
  - Running SQL queries and returning results.
  - Generating statistical summaries (mean, median, variance, correlations).
  - Scheduling jobs and alerts (e.g., notify when thresholds are breached).
  - Version control for datasets (rollback, compare).
  - Reusable transformation recipes (saved cleaning/preprocessing steps).
  - Data catalog and metadata management.
  - Collaboration tools (annotations, comments, sharing).
  - Automated report generation (PDF/PowerPoint with AI-generated narrative).

AI Integration:
- Connect to OpenAI/Anthropic/Groq APIs for natural language → SQL → visualization.
- Use LangChain or LlamaIndex for orchestration of workflows (ingestion → cleaning → EDA → visualization).
- AutoML integration (PyCaret, H2O.ai) for regression, classification, clustering, forecasting.
- AI assistant suggests relevant analyses and optimizes queries.

Python & R Integration:
- Python microservice (Flask/FastAPI) for advanced analytics:
  - Pandas, scikit-learn, statsmodels, matplotlib, seaborn.
- Optional R microservice (via plumber) for specialized statistical routines:
  - ggplot2, dplyr, caret.
- Expose both via API endpoints callable from the main backend.

External Tools:
- MySQL/PostgreSQL connectors for structured data queries.
- Tableau/Power BI integration via APIs or export pipelines.
- Google Sheets/Excel import/export.
- Cloud storage integration (Google Drive, OneDrive, AWS S3).

Other:
- Export results to PDF/Excel.
- Multi-language support (English/Arabic).
- Modular code with helpers for cleaning, visualization, and reporting.
- Data security: role-based access, encryption, audit logs, GDPR/CCPA compliance.
